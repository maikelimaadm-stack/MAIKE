# P4.3 — Map Geography Native Persistence

**Decisão:** D-PROD-32 · **Gate:** `gate:map-geography-native`

## Escopo entregue

Persistência nativa de `ConfiguracaoIcone`, `PontoReferencia` e `LinhaGeografica`:

- Prisma + migration `20261023180000_p4_3_map_geography_native`
- Backend Fastify autenticado: `/configuracao-icones`, `/pontos-referencia`, `/linhas-geograficas`
- Numeração `EntidadeCodigoSequencia` (escopo tenant) para `numero_ponto` e `numero_linha`
- DELETE físico apenas em ponto; linha continua com baixa lógica (`ativo: false`)
- Frontend: `@/apis/mapaGeografia` + reexport em `@/apis/mapa`
- Entidades removidas do `ENTITY_REGISTRY` e do catálogo offline Base44
