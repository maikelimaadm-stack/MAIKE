# P4.6 — Menus, Marcas e roteamento (hotfix produção)

**Data:** 2026-10-27  
**Branch:** `cursor/fix-menus-marcas-base44-516d-3d2e`

## Sintoma

- Itens do menu navegavam para `/marcas`, `/produtos`, etc., mas o React Router
  registrava rotas em PascalCase (`/Marcas`), gerando **404** e sensação de
  “menu não abre”.
- Marcas nativas dependiam de `empresa_selecionada_id` no `localStorage`; sem
  lista Base44 de empresas, a query ficava desabilitada e o CRUD parecia morto.

## Causa raiz

1. **Desalinhamento URL:** `createPageUrl()` (SSOT do menu) gera minúsculas;
   `App.jsx` usava `/${PageName}` com PascalCase.
2. **Empresa:** fallback de tenant nativo ausente quando `listEmpresas()` vem
   vazio ou falha.

## Correção

- Rotas canônicas via `createPageUrl(path)` + redirects PascalCase → minúsculas.
- Hook `useEmpresaSelecionadaId` (storage || `clienteId` JWT).
- `Layout` grava `clienteId` como empresa quando não há empresas Base44.
- `AuthContext` preenche `email` com `login` para permissões legadas.

## Verificação

- `npm run verify:all`
- Smoke: `tests/smoke/scope.test.jsx`, navegação em `appShell.test.jsx`
